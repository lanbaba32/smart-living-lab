# 智慧生活實驗室 Smart Living Lab

人工智慧與物聯網課程互動式網頁作品。以單一 HTML 檔模擬智慧家庭，讓使用者調整感測器數值，觀察條件規則如何控制燈光與風扇。

## 使用方式

下載 `index.html`，使用瀏覽器開啟即可。不需要安裝套件，也不需要 API 金鑰或硬體。所有文字、樣式與程式都包含在同一個檔案內，可離線使用。

## 互動功能

- 四種預設情境：舒適日常、夜晚回家、炎熱午後、外出模式。
- 溫度滑桿（15–40°C）、照度滑桿（0–1000 lx）與人體存在開關。
- 燈光及風扇視覺動畫，搭配即時設備狀態。
- 自動模式與手動模式切換。
- 條件規則說明、三題測驗、即時解析、計分與重新挑戰。
- 最近 30 次實驗紀錄與文字檔下載。
- 響應式版面、鍵盤操作與減少動畫偏好支援。

## 自動控制規則

1. 有人在家 **且** 照度低於 300 lx → 開燈，否則關燈。
2. 有人在家 **且** 溫度大於或等於 28°C → 啟動風扇，否則停止。

門檻是本作品自訂的教學規則。這是條件式自動化模擬，未使用機器學習模型，也未連接真實感測器或設備。手動模式不套用上述規則；切回自動時立即重新判斷。

## 建議展示流程

1. 點「夜晚回家」：觀察燈亮起、風扇停止。
2. 把溫度調至 28°C：觀察風扇開始轉動。
3. 把照度調至 300 lx：觀察燈關閉，了解 `<` 與 `≥` 的差異。
4. 關閉「有人在家」：觀察兩個設備關閉。
5. 關閉「自動控制」：自行切換燈光、風扇。
6. 完成測驗，下載實驗紀錄，整理觀察心得。

## 發布至 GitHub Pages

1. 在自己的 GitHub 帳號建立公開儲存庫，建議名稱 `smart-living-lab`。
2. 透過 **Add file → Upload files** 上傳 `index.html`、`README.md` 與 `提示詞與作品說明.md`，再提交變更。
3. 前往 **Settings → Pages**，Source 選 **Deploy from a branch**。
4. 選擇 **main** 分支與 **/(root)**，按 **Save**。
5. 等待發布完成，從 Pages 設定頁複製實際網址，作為作業連結。首次發布可能需要數分鐘。

`index.html` 必須放在儲存庫根目錄，不能只上傳壓縮檔。

參考：[GitHub Pages 官方快速入門](https://docs.github.com/en/pages/quickstart)。

## 技術與參考

- HTML、CSS、原生 JavaScript，無外部函式庫或字型依賴。
- 房間圖像以 CSS 繪製，少量系統符號與 emoji 依裝置顯示。
- 實驗紀錄僅存在當次頁面記憶體，重新整理會清空。
